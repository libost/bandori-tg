# How To Contribute

This is an open source project, run by volunteers in their free time. To keep this environment as 
pleasant as possible for everyone, please adhere to the [Go code of conduct](https://golang.org/conduct).

## Finding something to do

If you know what you want to do, feel free to skip this.

If you're looking for something, have a look at the 
[list of raised issues](https://github.com/libost/bandori-tg/issues) - This might help provide some inspiration.

## Making a code change

### If you spot a bug
1. Please create an issue on the [GitHub issue tracker](https://github.com/libost/bandori-tg/issues) and describe the bug in detail. 
2. Fork this repository from the `dev` branch. You should NEVER fork from the `main` branch, as this is the production branch.
3. Make your changes in a new branch.
4. Submit a pull request from your branch to the `dev` branch.

### If you want to add a new feature
1. Please create an issue on the [GitHub issue tracker](https://github.com/libost/bandori-tg/issues) and describe the feature you want to add.
2. Fork this repository from the `next-1.*` branch. You should NEVER fork from the `main` branch, as this is the production branch.
3. Make your changes in a new branch.
4. Submit a pull request from your branch to the `next-1.*` branch.
