# Security Policy

## Supported Versions

Each major release is supported until there are one newer major releases. For example, v1.3 was supported until the v1.4 release, and v1.4 was supported until the v1.5 release. We fix critical problems, including critical security problems, in supported releases as needed by issuing minor revisions (for example, v1.3.1, v1.4.1, and so on).


## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it to us using GitHub's security advisories feature. You can do this by navigating to the "Security" tab of the repository and clicking on "Report a vulnerability." Please provide as much detail as possible, including steps to reproduce the issue, any relevant code snippets, and the potential impact of the vulnerability. 

DO NOT create a public issue or pull request for the vulnerability, as this could expose the vulnerability to malicious actors before it is fixed.
